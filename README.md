Доработанная программа часов на ГРИ по проекту AlexGyver (Оригинал и все подробности см. по ссылке: https://alexgyver.ru/nixieclock_v2/ ). Добавлены будильник, термометр и новые эффекты, а также изменён принцип управления. 
Подробная инструкция по эксплуатации устройства, работающего по улучшенной программе, есть в файле "nixieClock_2_v2.7.ino", расположенном в папке исходного кода программы. 
Для правильной работы звукового сигнала будильника необходимо припаять к управляющей плате активный (не пассивный!) пьезоэлектрический звонок (см. файл "схема подключения звонка"), а также последовательно к нему подключить выводной резистор на 0,25 Вт 100 Ом (на плате есть место для него).
